1.What problem is the Java Platform Module System designed to solve?
Its designed to split the code into modules to make it easier to manage projects. It helps manage dependencies as well and controls which part of the code
can be seen by other modules.


2.To what extent does the Java Platform Module System implement the Principles of Package Cohesion & Coupling discussed in the lectures?
It improves cohesion by keeping related code together in modules and it reduces coupling by telling the modules which can access eachother.
